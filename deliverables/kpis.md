# Primary KPI

Overall accuracy of the dataset should be => 70%. 

First try the model with unsupervised learning to see how the model classifies images.
Also try supervised learning which should be an increase in accuracy overall.

# Secondary KPI

Accuracy should be consistent across gender groups and age groups. 
If there is a significant gap (1$$\sigma$$), then identify which demographics have these gaps. 
Divide the samples based on demographics with larger errors and use these more in the training to see how it affects the results.
